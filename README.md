# Portfolio

Сайт-портфоліо продуктової дизайнерки. Плейн HTML + CSS + мінімум ванільного JS, без збірки.

## Структура

- `index.html` — головна (герой, кейси, про мене, контакти)
- `case/deal-flow.html` — сторінка кейсу
- `about.html` — про мене
- `resume.html` — резюме, друкується як A4 PDF (Ctrl/Cmd+P)
- `404.html` — сторінка помилки
- `assets/` — стилі та скрипти

## Локальний перегляд

```
python3 -m http.server 4173
```

Відкрити http://localhost:4173

## Деплой

GitHub Pages, гілка `main`, корінь репозиторію.
