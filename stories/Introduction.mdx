# Дизайн-система портфоліо

Тут зібрані основи й компоненти сайту. Усе рендериться тим самим
`assets/css/style.css`, що й сторінки, тож Storybook не може розійтися з сайтом:
змінив токен у CSS — оновилось і тут.

- **Основи / Кольори** — палітра Apple і ролі `--color-*`. Значення читаються
  прямо з `:root`, тож нові токени зʼявляються тут самі.
- **Основи / Типографіка** — 9 текстових стилів. Перемкни вьюпорт на панелі
  (Mobile 375 ↔ Desktop 1920), щоб побачити, як масштабується шкала.
- **Компоненти** — хедер, картка проєкту, кнопка «Більше робіт», посилання,
  рядок роботи, футер. Наводь курсор — ховери ті самі, що на сайті.

Повна специфікація для Figma — у `DESIGN-SYSTEM.md` у корені репозиторію.

## Запуск

```bash
npm install
npm run storybook
```

Відкриється на http://localhost:6006. Статична збірка — `npm run build-storybook`
(тека `storybook-static`, у git не потрапляє).

Що тут не працює: анімації, які запускає `main.js` при завантаженні сторінки
(магніт кнопки, поява футера, стиснення хедера при скролі). Стиснення хедера
можна покрутити контролом у його історії.
